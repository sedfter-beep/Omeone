    自製筆刷｜筆尖編輯器

    在左側畫布畫出筆尖形狀（黑色＝墨水、透明＝無），或匯入圖片當筆尖；右側調整間距、旋轉、散布與壓力。下方預覽會即時顯示筆觸，編輯內容立即套用到工具列的「自製筆刷」。

    自製字型｜手繪字集與字型檔

    兩種方式：①輸入想要的字集，逐字手繪成「手繪字型」；②匯入 TTF／OTF／WOFF 字型檔。完成後在畫布選「文字」工具，並從底部列的字型選單挑選即可。字型只存在本機瀏覽器，匯入字型前請確認授權允許使用。

    尚未建立字集。按「建立／更新字集」開始。手繪字型匯出為本程式專用的 JSON 備份，不是可安裝到系統的 TTF。

    各模式通用｜縮時攝影紀錄

    記錄目前畫布的變更快照，依「貼圖設計」標記專案模式。開始後的每次繪圖放開及自動儲存會觸發快照。快照只存本機，可回放並嘗試匯出 WebM；錄影期間最多保留 180 個變更影格。

    尚未開始錄影。建議正式創作前先試錄幾筆，並定期匯出備份。

    ⑤ 真正雲端帳號與跨裝置同步（Supabase）

    需要你自己的 Supabase 專案網址與 anon/public key。帳號密碼由 Supabase Auth 處理；作品資料存入你專案中的資料表，並套用下方 RLS 權限政策。

    免註冊驗證需在 Supabase Auth 關閉 Email confirmation；新帳號未驗證信箱前，系統無法確認信箱歸屬。請勿以 Email 作為密碼。

    尚未連線。首次設定請先在 Supabase SQL Editor 建立資料表並啟用 RLS。

    Supabase 資料表 SQL（首次設定貼上執行）
    create table if not exists public.omeone_projects (project_id uuid primary key, user_id uuid not null references auth.users(id) on delete cascade, project_name text not null, project_data jsonb not null, updated_at timestamptz not null default now());
alter table public.omeone_projects enable row level security;
create policy "Users manage own OMEONE projects" on public.omeone_projects for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
create index if not exists omeone_projects_user_updated on public.omeone_projects(user_id, updated_at desc);

    OMEONE 3.2｜AI 智慧繪圖版

    線稿分區、破線提示、區域上色、色彩輔助與手動修正整合成一條流程。辨識在這台裝置上以影像分析完成，作品不會上傳；辨識資料、上色、補線都放在獨立圖層／獨立資料，原始線稿不會被改動。

    ① 線稿分區辨識 ＋ ② 破線提示

    紅圈＝缺口大於容許值、可能造成顏色溢出的地方（紅色淡底＝可能未封閉的區域）；黃圈＝小缺口，已自動補合。缺口容許越大，越能忽略斷線，但太大會把細窄區域黏在一起。

    尚未辨識。選好線稿圖層後按「辨識線稿並建立區域」。

    ③ 區域上色

    在畫布選「區域」工具後點區域即可上色。每一步都可用工具列「復原／重做」（或 Ctrl／⌘＋Z）還原。顏色放在獨立的「3.2 區域上色」圖層（色彩增值混合），隨時可隱藏、調整不透明度或刪除。

    ④ 色彩輔助

    以「目前顏色」為基準的配色建議（改色後自動更新），點色票即可套用。

    常用色（自動記錄你上過的色）
    日系色盤

    ⑤ 手動修正辨識

    合併：依序點兩個區域。拆分：畫一條貫穿區域的切線，不留下可見線條。補線：畫線封閉缺口，線畫在「3.2 補線」圖層，下次辨識也會算進去。刪除：把誤判區域標成灰色、不再上色，再點一次還原。拆分／補線只重算受影響的區域，其他區域與顏色不變。

    設計原則與限制

    • AI 辨識結果不會覆蓋原始線稿；辨識資料另存，上色與補線各有獨立圖層。
    • 每個區域都能重新選取、修改、復原；合併、拆分、補線、刪除、上色都在同一個復原堆疊。
    • 辨識為本機影像分析（線條門檻＋連通區域＋缺口容許），不是雲端生成式 AI，不會上傳作品。
    • 支援觸控、Apple Pencil 與滑鼠；補線／拆分以單指或筆畫線，雙指仍是縮放與移動。
    • 區域資料不隨作品儲存：重開作品後請再按一次「辨識」，既有上色會依位置沿用；合併、刪除、拆分需重做（補線圖層會保留）。
    • 「所有顯示中的圖層」模式以不透明度疊合圖層，不計入遮色片與混合模式。
